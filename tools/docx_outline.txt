021	heading 1(2)	Abstract
022	-	With the rapid rise of mini-programs and the increasing public awareness of legal rights, people's attention to national and social public interests has grown significantly. Public interest litigation, as a crucial means of safeguarding public interests, has become increasingly prominent. However, in practice, issues such as scattered sources of public interest litigation case leads, low efficiency in analysis and evaluation, and complex case process management have become key factors affecting case-handling efficiency.
023	-	In today's era of rapid big data development, leveraging existing technological means to optimize the case-handling process for public interest litigation has become an inevitable choice. Based on this, this project designed and developed a mini-program system to assist in public interest litigation case handling, aiming to improve efficiency and help the public better report violations and learn about the law. The front-end web management interface of this system was developed using Vue, while the mini-program front-end was built with UniApp. The back-end was architected using the Spring Boot framework, combined with a MySQL database to store basic system data and Alibaba Cloud OSS for media file storage. The system encompasses the following modules: law enforcement personnel management, user management, consultation management, case management, lead management, knowledge base management, and data statistics. Through the coordinated operation of these modules, the system achieves refined management of the entire public interest litigation case-handling process.
